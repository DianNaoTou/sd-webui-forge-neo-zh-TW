## 已執行驗證

- Linux Python 3.12、真實 **Torch 2.14.1+cpu／Kitchen 0.2.40／Gradio 4.40.0** 的完整 unittest：**180 項通過、零跳過**。
- 完整 Python `-O` unittest：**180 項通過、零跳過**；擴充 CI 為完整最佳化回歸，包含 Spectrum。
- Node：**14 項通過、零跳過**（原 WD14 4 項＋JSON 10 項）。DOM 為事件 recorder，不是瀏覽器視覺測試。
- 新 2.31 測試實際執行原函式或原 AST：小尺寸 MOSS 前向的真實 PyTorch／Kitchen eager 算子、Qwen delta rule 與逐步 recurrence 數值比較、SLG 區間／CFG=1／非 MOSS／callback 排序、字串與列表權重前綴、meta 權重實體化、RGBA、VAE None、生成／清理例外後還原、數字／排程 LoRA、CPU 量化能力、舊 ONNX parser、tokenizer SHA。
- Windows x64／Python 3.13 依賴解析：主 requirements、ADetailer、WD14、preprocessor、Gradio 與相應 ORT，CUDA **165** 套件、XPU **178** 套件；XPU 無 NVIDIA 套件。保留 Pillow 10.4／HEIF 0.22／Gradio 4.40／MarkupSafe 2.1.5。
- 原始碼編譯檢查；本輪修改 Python 檔的未定義名稱檢查；差異空白與換行檢查（保留既有 CRLF），UI Freeze 與翻譯字典完整性。
- 無模型 CPU 啟動（僅內建插件）：MOSS／文字編碼器 import、ControlNet UI、JSON Builder 可建立；此項不含使用者外掛完整啟動、不做模型生成。實際 HTTP `/`、`/config` 與 JSON compile／decompile／main 三個腳本皆回應 200，腳本內容與原檔一致，config 含 JSON Builder 頁籤（2866 個元件），沒有腳本載入例外。
- CI 對 Windows 新增 2.31 真實 CPU 數值回歸，保留 Windows 原生檔案共享／設定／XPU／Git ZIP 檢查；發布工作依賴兩平台通過，固定 ZIP 與 checksum 不覆寫既有版本。

## 自動檢查的界線

本環境沒有 NVIDIA／Intel GPU，也沒有實際模型權重。未驗證 CUDA／XPU kernel、MOSS 真實權重／品質／顯存容量、LoRA 視覺效果、LayerDiffuse 半透明品質、長時間 Hires／OOM／DEVICE_LOST 與完整瀏覽器拖曳。測試所用 CPU transport／裝置 stand-in 在測試註解中說明，不能視為完整 Forge GPU 啟動。
