# 2.31-tw.1-test.3：擴充內附外掛的語系檔翻譯

延續 Test 2，僅更新 `neo-test`；正式 `neo` 仍為 2.30-tw.1。

## 語系處理

- **Image2Prompt**：介面標題、模型／格式顯示名稱、按鈕、進階說明與狀態訊息使用英文原文＋`localizations/zh_Hant.json`；保留舊中文模型／格式輸入的相容別名。模型提示指令、生成結果與使用者自訂指令不做介面翻譯。
- **Civitai 下載器**：頁籤、設定與提示、預覽選項、下載進度、取消／錯誤訊息、模型卡片按鈕與刪除確認改用字典；保留舊中文預覽選項與自動資料夾值的接收相容性。
- **WD14／PixAI／Camie**：將新增的延後下載說明及等待按下辨識提示移至字典；模型名稱與推論不變。
- **LoRA 中繼資料編輯器**：模型預設、訓練標籤、觸發詞、權重、負向與隨機提示詞、備註改用英文來源；模型版本底層值不變。
- **其他內建外掛**：補上 RadialAttention、ControlNet 畫布編輯器、PiD、額外設定區、柔性局部重繪與 Ultimate Upscale 的缺少詞條，HTML／Markdown 依實際文字節點補翻。ADetailer、Spectrum、Sparse Attention 的直接元件標籤已有字典覆蓋，未為了翻譯重寫生成流程。
- 本版新增 **168** 個根字典詞條，Test 2 既有翻譯值不變。回呼翻譯使用目前選定語系；先翻譯固定模板，再代入檔名、路徑與模型名稱，不翻譯資料內容。缺少或格式錯誤的翻譯會回退英文。

**Prompt All-in-One 有自己的 `i18n.json` 與獨立語言選單**，保留既有設計。它的介面／翻譯目標語言由外掛內選單控制，不會因 WebUI 切英文就自動覆寫。需要整個畫面都是英文時，也請在該外掛選 English。後端診斷日誌、模型驗證例外、外部服務回傳文字並非全部完成語系化；此版不宣稱全專案無中文原始碼。

## 一併修正

- 真正建立 Gradio 4.40 的 Civitai 頁籤時發現 `Image(fill_width=True)` 不支援；移除此無效參數。
- 此版本的 Gradio 也沒有 `Label.update`／`Textbox.update`；改用 `gr.update`，避免下載、進度與取消提示呼叫失敗。
- Image2Prompt 傳送到主提示詞欄位後改用既有 `switch_to_txt2img`／`switch_to_img2img`，避免靠英文頁籤文字比對而在中文介面失敗。

## 驗證與更新

- 本機 Python 一般與最佳化模式各 192 項通過、零跳過；真實 Gradio 介面建立、英文來源、繁中／英文動態回呼、舊選項相容、下載失敗清理及翻譯模板欄位檢查。
- Node 19 項通過、零跳過，使用實際 localization.js 與 Civitai 卡片事件，驗證通知、確認對話框與 tooltip 的中文／英文；不連線下載、不刪除模型。
- Linux 完整回歸與 Windows Gradio／語系回歸通過後才由 CI 建立固定測試 ZIP。沒有進行 GPU 模型生成或瀏覽器視覺驗收；既有 GPU 限制仍適用。
- 更新 `neo-test` 後重啟 WebUI；切換 WebUI 語系時套用設定並重新載入介面。既有測試版標籤與附件不覆寫。
