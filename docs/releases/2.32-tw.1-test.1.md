# 2.32-tw.1-test.1｜Forge Neo 2.32 上游同步測試版

本版僅更新 `neo-test`；正式分支 `neo` 與正式版 2.31-tw.1 保留。待使用者實測確認後，再另行整合及發布正式版。

## 變更

- 合併上游 2.32 的 5 個提交：`4f4284b0` → `a31a8ba0a5ee2844dc4d4e8105cb056ba0b7f5d7`。
- GPU 啟動檢查改用 `torch.accelerator`，實際建立張量、執行運算並傳回 CPU，及早發現裝置無法運作的情況。
- Qwen3-VL 圖片嵌入先在文字編碼器裝置處理，再將嵌入與 deepstack 傳回目標裝置。
- ControlNet 新安裝的 InsightFace 固定為上游指定的 2.1，使用 `--no-deps`；沿用整合版的共用 ONNX Runtime 安裝器，避免 CPU／GPU 套件互相覆蓋。已存在的 InsightFace 沿用上游邏輯，不強制重裝。
- 保留 CUDA／XPU Torch 分流、ONNX 版本限制、Intel WD14 OpenVINO 隔離、模型路徑與設定備份等既有修正。
- 同步上游 Python 3.13 專案資訊、檢查設定及英文 README；繁中 README 繼續保留整合版安裝方式。
- 補入 38 個繁中詞條，涵蓋高解析度修復、蒸餾 CFG、LoRA 替換、提示詞快捷鍵、排程器與門檻等。翻譯集中於 `localizations/zh_Hant.json`，介面保留英文來源，透過語言選單切換並重新載入介面。既有插件的獨立翻譯機制維持。

## 驗證範圍

本地 Python 一般與最佳化模式各執行 218 項：214 項通過、4 項因需 Windows Junction／獨立 OpenVINO 執行環境而略過；前端 20 項測試與 Python 編譯檢查通過。新增 GPU 探測失敗、Qwen3-VL 裝置傳遞、ControlNet 安裝及中英文切換回歸。GitHub Actions 另驗證 Windows 與獨立 OpenVINO 執行環境，通過後由既有流程打包測試版。
Windows、RTX 5060 Ti／Intel Arc 實機啟動與出圖、跨裝置 Qwen3-VL 推論，仍待實測。

## 更新與回滾

關閉 WebUI，在既有 `neo-test` 安裝目錄執行：

```bat
git branch --show-current
git pull --ff-only
```

第一行應顯示 `neo-test`，更新後以原啟動檔啟動。版本顯示應為 `2.32-tw.1-test.1`。

回到更新前測試版：

```bat
git switch --detach 19c6e3daa494abf57c414e4f4046c3991240baa0
```

回到新版：

```bat
git switch neo-test
```

上述切換只改程式版本，不刪除模型、輸出、設定或虛擬環境。
