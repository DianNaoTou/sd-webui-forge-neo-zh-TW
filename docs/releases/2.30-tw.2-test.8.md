# 2.30-tw.2-test.8：ZIP Git 更新測試

這是 neo-test 的測試版，正式版仍為 2.30-tw.1。本輪保留 Test 7 功能，新增可直接 Git 更新的發布包裝。

## 下載與更新

在本頁 Assets 下載 **neo-test.zip**，解壓到新資料夾，保留隱藏的 `.git`；電腦需有 Git。
附 neo-test.zip.sha256 供檢查下載完整性。Source code (zip) 是 GitHub 原始碼封存，不包含 Git。

以後先關閉 WebUI，在解壓後的專案資料夾執行 `git pull`，更新 **neo-test 測試分支**。
下載內容固定於本次 CI 驗證提交，日後 pull 才前進；不會轉到正式 neo。
不可直接把新 ZIP 覆蓋舊安裝。舊版不含 Git 的 ZIP，本輪沒有自動原地轉換機制。

## 保護與限制

- 只允許快轉，停用自動 stash；本地修改衝突、歷史分歧及 ignored 同名覆寫時停止，保留原檔。
- 不強制 reset／clean，不備份、刪除或搬移使用者模型、輸出及環境。
- git pull 本身不下載模型、不建立 Python 環境；啟動後仍沿用既有套件檢查。
- 受追蹤啟動檔與插件程式仍會更新；自行修改後可能需要處理差異。
- 未改推論、CUDA／XPU 依賴或環境路徑。舊 Intel 正式環境轉到 Test 7 的官方 profile 仍需新 venv，獨立快取可能重抓缺少資料。
- Test 7 舊設定確認／備份流程與尚待 GPU 實機驗證限制維持。本版不宣稱解決所有 OOM、DEVICE_LOST 或 PermissionError。

本機 147 項 Python 回歸零跳過、59 項 Python -O 與 4 項 Node 測試通過。發布前另由 Windows 檔案／設定／ZIP Git 測試把關，再驗證實際專案 ZIP 的 SHA、upstream 與完整性。
真實 Git 測試涵蓋連續更新、資料保留、修改衝突、分歧及 ignored 碰撞；不代表完整 GPU／插件驗收。
