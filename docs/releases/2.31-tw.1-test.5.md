# 2.31-tw.1-test.5：Intel Arc 統一啟動與 WD14 GPU 加速

發布日期：2026-10-25。僅更新 `neo-test`；正式 `neo` 維持 **2.31-tw.1**。

## 相較 Test 4

- **只保留 `webui-user-intel-arc.bat` 一個 Intel Arc 啟動檔**，其內容改用 Test 4 已測試的 WD14 GPU 流程；原 CPU-only 啟動內容淘汰。
- 移除 `webui-user-intel-arc-wd14-gpu.bat`，之後直接執行原名 `webui-user-intel-arc.bat`，同時啟用官方 XPU 生圖與獨立 OpenVINO WD14 GPU 辨識。
- 保留 GPU 準備、模型編譯或推論失敗時自動退回 CPU、逾時處理與顯式 CPU 選項。移除的是舊啟動入口，不是移除錯誤恢復機制。
- 沿用 `venv-xpu-official`、`runtime/xpu-ab/official`、7862 埠與 `runtime/wd14-openvino` 的既有環境／快取，不搬移或刪除模型、個人設定及虛擬環境。NVIDIA 啟動檔與 CUDA 流程不變。
- 保留 Test 4 後已加入測試分支的 Forge Couple 繁中詞條；本版未安裝新的 Forge Couple 外掛。
- 同步文件中最新正式版為 2.31-tw.1，區分正式版 CPU WD14 與本測試版 GPU 入口。

## 更新與使用

關閉 WebUI，在既有測試分支執行 `git pull --ff-only`，或下載本版 Release 的 **neo-test.zip**（含 Git，追蹤 `origin/neo-test`）。不要以 ZIP 直接覆蓋個人資料；原始碼 ZIP 不含 Git。

```bat
webui-user-intel-arc.bat
```

首次會在 `runtime/wd14-openvino/venv` 準備 OpenVINO 2026.3.1 與 numpy 2.3.5；Test 4 使用者直接沿用。模型仍在辨識時按需下載。其他啟動參數照常傳入，多 GPU 可用：

```bat
webui-user-intel-arc.bat --wd14-device GPU.0
```

GPU.0 不保證是 B580，請查看實際裝置名稱。辨識時看到 `[WD14 GPU] OpenVINO GPU worker` 與裝置名稱才代表模型 GPU worker 成功；若顯示退回 CPU，請提供相鄰錯誤紀錄。原有批次檔捷徑請指向唯一入口；Git 更新會刪除未修改的舊專用啟動檔，若個人曾修改該檔，請先保留參數並處理 Git 差異，不要強制覆蓋。

## 驗證與限制

使用者於 2026-10-25 回報：B580 使用 Test 4 專屬 GPU 啟動檔，WD14 功能初步測試正常。未提供完整模型清單、效能數據或長時間測試結果，不能據此宣稱所有 Arc、PixAI／Camie 或所有模型已完整驗收。Test 5 沿用該 GPU 實作，修改啟動入口及文件。

WD14 GPU 與生圖仍共用顯存／驅動。既有 B580 OOM、HR 較慢、DEVICE_LOST 限制保留；本版不宣稱全面修復。獨立套件環境不影響 NVIDIA venv。更多 worker 範圍、數值差異、快取與退回設計見 [Test 4 歷史說明](2.31-tw.1-test.4.md)，該文的雙啟動檔操作已由本版取代。

CI 執行 Linux WebUI 一般／最佳化、Node、Windows 核心回歸，以及 Windows／Linux 實際 OpenVINO worker 一般／最佳化測試，全部通過才建立測試 ZIP。
