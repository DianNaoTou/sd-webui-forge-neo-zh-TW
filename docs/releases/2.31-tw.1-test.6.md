## 驗證與限制

本地 Python 一般／最佳化回歸、前端事件測試及編譯檢查；發布由 GitHub Actions 的 Linux／Windows／OpenVINO 檢查通過後自動打包。
NVIDIA RTX 5060 Ti、Intel Arc B580／A380 實機出圖：未測。既有 Intel 高解析度效能與連續生成限制尚未宣告解決。

## 更新與回滾

既有 neo-test Git 安裝，在專案目錄執行 git pull --ff-only，再用原啟動檔啟動。
更新前如有自行修改受版本控制檔案，先保存修改。

回到更新前測試分支：
git switch --detach bd3604b5a3e900436c7f03b9e8bb0d66913dee17

回到新版：
git switch neo-test

回滾指令只切換程式；不移動模型、不刪除設定或虛擬環境。本版依賴安裝器會處理 comfy-kitchen 版本。
