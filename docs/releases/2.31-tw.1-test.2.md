# 2.31-tw.1-test.2：補齊語系檔翻譯與英文切換

本版只更新 `neo-test`。延續 [Test 1](2.31-tw.1-test.1.md) 的全部功能，正式 `neo` 仍為 2.30-tw.1。

## 修改

- 修正 ImageStitch 說明半中半英：粗體與 tooltip 標籤將句子拆成不同 DOM text nodes，舊整句翻譯無法命中。依實際文字片段補上 `localizations/zh_Hant.json` 詞條；ImageStitch 的原始英文 HTML 不改、不寫死中文。
- LayerDiffuse 的介面標題、說明、按鈕、生成方法、縮放模式、提示詞欄位、權重與停止比例均改用英文原文；中文由語系檔提供，與 JSON 構圖編輯器使用相同的語系選擇原則。
- 切換為英文（語系 None）後，套用設定並重新載入介面；必要時重新整理頁面。中文語系載入翻譯表，英文不載入中文覆蓋。不在既有已翻譯 DOM 上直接覆寫使用者輸入。
- LayerDiffuse API 的正式名稱固定為 `LayerDiffuse`；原測試版 `LayerDiffuse 圖層透明生成` 保留為相容別名。英文 method／resize 值、參數順序、生成資訊與模型權重均不變。
- 本輪處理介面語系；底層診斷日誌／驗證例外不屬於此次畫面翻譯範圍，未以翻譯重寫推論或錯誤處理。

## 驗證

- 本機完整 Python 一般與 `-O` 模式各 **185 項通過、零跳過**。
- Node **17 項通過、零跳過**，包含實際 ImageStitch HTML 文字片段、原始 localization.js、繁中與英文重新載入，以及 JSON Builder 的實際翻譯表。
- 真實 Gradio 4.40 元件驗證 LayerDiffuse 的英文來源、選項底層值與 12 個 API 參數順序；驗證舊 API 名稱與新名稱指向同一腳本。
- 修正 Windows CI 測試環境漏裝 Python 3.13 所需 audioop-lts（主專案 requirements 原已包含）；強制確認 Gradio 可載入，避免 UI 測試因匯入失敗而被略過。
- CI 加入 Windows 語系／Gradio／API 相容測試，Linux 維持完整一般與最佳化回歸；兩平台成功後建立本版固定 ZIP 與 checksum。執行結果以 Actions 為準。
- 沒有執行 GPU 生成；不因本次翻譯修補宣稱修復 Test 1 列出的 GPU 已知問題。未執行實際瀏覽器視覺比對，文字渲染以原始翻譯引擎的 DOM 測試驗證。
