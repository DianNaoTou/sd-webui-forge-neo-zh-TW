## 整合修正

- ImageStitch 只有完整編碼成功後才記住快取；編碼失敗或中斷會清理部分參考圖，下一次相同輸入可重試。快取辨識保留彩色與透明度資訊，並區分載入的模型實例。
- 擴充更新工作數在單核心、CPU 數未知時至少為 1，並保留最多 16 個工作執行緒。
- 擴充索引安裝的四個回傳值對應四個介面輸出；停用／更新清單及還原確認各使用獨立隱藏元件。
- 索引首次載入的預設隱藏標籤與顯示清單一致；2025-01-01 納入 2025+ 篩選。
- 擴充存取限制及 JSON 清單驗證在 Python 最佳化模式下仍有效。

## 繁體中文

新增介面、參考圖設定與動態提示的繁中詞條集中於 **`localizations/zh_Hant.json`**。Ultimate Upscale 原本的 28 個詞條合回同一檔案，保留合併前實際生效的翻譯並移除其重複語言檔。介面來源與 API 選項值維持英文，可切換語言並重新載入介面。

Prompt All-in-One 原有獨立語言選單及 i18n 資源沿用；它包含多語言與標籤資料，不強行改成 WebUI 字典。終端日誌、外部擴充描述及模型名稱不宣稱已全部中文化。

關閉 WebUI，在既有測試版目錄執行：

```bat

git pull --ff-only
```

應顯示 `neo-test`；更新後沿用原啟動檔，版本顯示 `2.32-tw.1-test.2`。若 Git 提示本機修改衝突，保留修改先處理，不使用強制重設。

```bat
git switch --detach f4a31296dcdbd22be9434e2d814dc449b242f681
```

回到測試分支：

```bat

```
