# 2.32-tw.1-test.4｜NVFP4、JSON 構圖與載入修正

日期：2026-11-21。整合至 `neo-test`；正式 `neo` 維持 2.32-tw.1。

## 上游同步

同步 `e67193d97cc034a7d285973b9ac32c2d3b5b2768..db117cb2ac33f6a11ec281ff71ffd4cd02b2f05a`，共 10 個提交。上游版本號仍為 2.32。

- **GGUF NVFP4**：新增 NVFP4 解碼，以及符合硬體能力與矩陣形狀條件的 NVIDIA Tensor Core 路徑。這是量化格式的支援，並非將所有現有 SDXL 模型自動轉換成 NVFP4。Intel XPU 沿用 PyTorch 解碼，不啟用 NVIDIA 核心。
- **GGUF 載入**：調整 Linear／Conv2d／Embedding 權重註冊與重載，保留量化層的壓縮權重；普通層載入量化資料時先解碼。修正 pin_memory 的資料複製。
- **模型清單**：讀取單一 Checkpoint 遭遇 OSError 時記錄並繼續，避免整份模型清單中斷。附加模組選項的過期名稱防護，本整合版已具備並保留。
- **日誌**：Rich 日誌寫入配合 tqdm，降低進度條被打斷；NVIDIA 使用 CUDA 13 之前的 Torch 時新增提示，不自動重裝 Torch。
- **CodeFormer**：`spandrel-extra-arches` 改為選用；新環境要使用 CodeFormer 時，須手動將此套件安裝至使用中的虛擬環境。既有已安裝套件不會被移除。
- 移除舊 ADetailer 推薦訊息；保留本專案既有擴充載入保護。

## JSON 構圖編輯器

依既有 UI Freeze 規範保留 **JSON Builder 獨立頁籤**、匯入對話框及「傳送至文生圖／圖生圖」，沒有採用上游將編輯器移至額外網路頁籤的配置。

整合的新功能：

- 彩色區域、雙擊置頂、適合檢視範圍、清單展開／收合。
- 從本機或所選目標圖庫載入背景參考。背景僅作視覺參考，不會自動傳入生成流程。
- 修改畫布尺寸時按比例調整方框位置。
- 「提示詞目標」可選文生圖或圖生圖；「從提示詞讀取」讀取該目標現有提示詞與尺寸。
- 雙擊描述欄位可連動目標主提示詞，以使用自動補全；再次雙擊或切換目標時解除連動並還原原主提示詞。編輯結果留在構圖中，按傳送才編譯整份構圖。
- 解除連動／傳送時套用已選樣式，保留負面樣式文字後才清除樣式選取。樣式無法完整取得時保留選取狀態。

保留前版的 JSON 驗證、可見錯誤及可選 palette／tags 欄位；新增標籤、提示與使用說明集中於 `localizations/zh_Hant.json`，可切回英文。既有 CUDA／XPU 分流、WD14 OpenVINO 隔離、Pillow／HEIF／protobuf 相容限制與模型／設定路徑沿用。

## 驗證與限制

- 真實 CPU Torch／Gradio 環境執行完整 Python 一般與 `-O` 回歸，各 230 項：226 通過、4 項因 Windows Junction／獨立 OpenVINO 環境條件略過；23 項 Node 前端回歸、Python 編譯與 Git 空白檢查通過。
- 新增 NVFP4 128 種 scale 編碼及正負 nibble 與獨立 GGUF 解碼器的數值比較、GGUF 重載／參數註冊與普通 meta 層解碼測試。pin_memory 僅替換實際 pinned allocation，驗證量化中繼資料複製，未驗證 GPU pinned transport。
- Node 執行原始編譯器及前端程式的事件回歸，涵蓋雙向連動、還原提示詞、正負樣式、尺寸縮放與可選欄位保存。使用最小 DOM，不等同完整瀏覽器驗收。
- 本環境的 Chromium 啟動受 socket 權限限制，**尚未完成完整瀏覽器視覺驗收**。RTX 5060 Ti／Intel Arc B580 啟動、完整模型生成、NVFP4 Tensor Core、Triton 與效能均未實機驗證。
- GitHub Actions 執行 Linux／Windows CPU 與獨立 OpenVINO 檢查，全部成功後由既有流程發布測試 ZIP；以 Actions 實際結果為準。
