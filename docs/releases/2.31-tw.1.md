# 2.31-tw.1 正式版

發布日期：2026-10-25。相較上一正式版 **2.30-tw.1**，本版包含：

- **更新至 Forge Neo 2.31**：新增 MOSS-Image、Qwen3.5 文字編碼器、JSON 構圖編輯器與 SLG 跳層引導。
- **新增 LayerDiffuse 圖層透明生成**，以及 WD14 的 PixAI／Camie 標籤模型；新增模型依需要下載。
- **更新核心環境**：新 NVIDIA 安裝採用 Torch 2.14.0+cu130；Intel 使用獨立官方 XPU 環境與 Torch 2.14.1+xpu，並同步相關相容套件。既有 NVIDIA 環境不會只因 Git 更新就強制換版 Torch。
- **ZIP 支援 Git 更新**：正式 Release 附件 `neo.zip` 包含 Git 資訊，安裝 Git 後可直接在專案資料夾執行 `git pull` 更新正式分支。
- **改善中文化與操作體驗**：補齊外掛翻譯與英文切換，改善 PNG／WD14 提示詞傳送、模型刷新及外掛介面相容性。
- **修復各種 bug、改善穩定性**，涵蓋 ControlNet、Spectrum、VAE／XYZ 與模型載入等流程。

本版以已測試的 **2.31-tw.1-test.3** 為來源，**不包含 Test 4 的 Intel WD14 OpenVINO GPU 實驗修改**。Intel WD14 辨識維持原本 CPU 路徑；實驗功能繼續留在測試分支。B580 仍可能遇到記憶體不足、HR 較慢或 DEVICE_LOST，本版不宣稱全面修復。
