# 2.32-tw.1｜Forge Neo 2.32 繁體中文整合版

**2.32-tw.1 正式版發布。** 本版同步 Forge Neo 2.32，整合模型相容性、Intel WD14 GPU 辨識、繁中介面與操作流程更新。

## 更新內容

- 支援 ANIMA RGBA 透明圖片與 Moss-Image 編輯模式，加入 XYZ 文字編碼器比較、LoRA 提示詞搜尋／取代與模型卡片附加模組設定。
- 改善模型清單排序、Attention 精度、量化權重、LoRA 載入處理與 VAE 推論路徑。
- 更新 GPU 啟動運算檢查、Qwen3-VL 裝置配置與 ControlNet InsightFace 安裝，保留 CUDA／XPU 與 ONNX Runtime 相容性分流。
- Intel Arc 統一使用 `webui-user-intel-arc.bat`，官方 XPU 生圖與 WD14 OpenVINO GPU 辨識分別使用獨立環境，保留 GPU 辨識失敗退回 CPU。
- 同步 Prompt All-in-One 提示詞分割、行號及空行處理，補齊繁中翻譯與英文切換，保留模型路徑、設定與插件相容性修正。
- 翻譯上游新版介紹與使用方式，統一專案介紹用語為「繁體中文整合版」。`tw` 版本標記、儲存庫名稱與路徑保持不變。

[Forge Neo 2.32 新功能與使用方式](../forge-neo-2.32.md)

## 下載與更新

- [neo.zip（含 Git）](https://github.com/DianNaoTou/sd-webui-forge-neo-zh-TW/releases/download/2.32-tw.1/neo.zip)
- [SHA-256 校驗檔](https://github.com/DianNaoTou/sd-webui-forge-neo-zh-TW/releases/download/2.32-tw.1/neo.zip.sha256)

正式版 ZIP 追蹤 `origin/neo`。已有正式版 Git 安裝，關閉 WebUI 後在專案目錄執行：

```bat
git branch --show-current
git pull --ff-only
```

分支應為 `neo`；更新後使用原啟動檔。若目前仍在 `neo-test`，請先確認工作目錄無需保留的未提交修改，再切換 `neo` 並更新；也可將正式版 ZIP 解壓至新目錄。

套件不含模型、輸出、個人設定、虛擬環境與快取。請勿直接以 ZIP 覆蓋既有個人資料。
