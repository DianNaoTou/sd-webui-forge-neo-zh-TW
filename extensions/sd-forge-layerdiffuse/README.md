# LayerDiffuse｜Forge Neo 繁中測試整合

在文生圖／圖生圖展開「LayerDiffuse 圖層透明生成」，勾選「啟用」。預設關閉，不會自動下載權重。

## 建議先測

1. 使用一般 SDXL 模型，選「只生成透明圖片（Attention 注入）」，批次 1、權重 1、停止比例 1。
2. 關閉 ADetailer、Hires. fix 與其他圖層／Attention 插件，輸出格式選 PNG。
3. 第一次會下載該方法權重與透明解碼器，合計約 0.95 GB。其他方法另按需下載，部分權重單檔約 3.62 GB；不會一次下載全部。
4. 確認成功後，關閉 LayerDiffuse 再生成一次，檢查一般圖片是否恢復正常，再依實機清單測 Hires 與其他模型。

權重存於 Forge 的 `models/layer_model/`（沿用 models_path，支援既有模型資料夾設定）。既有檔案先驗證，不符合固定版本的 SHA-256 時保留原檔並停止，請自行移開該檔後重試。下載只使用固定版本清單中的所選權重；不安裝或升降級 Torch、Diffusers 等套件。

## 測試限制

- 僅一般 SD1.5／SDXL 架構；專用 Inpainting、SDXL Refiner、其他模型家族不列為支援目標。Illustrious 需保有 SDXL 架構，畫質與透明效果待實測。
- SD1.5：前景／背景雙圖模式的批次必須是 2 的倍數；同時生成模式必須是 3 的倍數。權重目前只支援 1，其他值會停止並提示。
- 暫不支援與 ADetailer 同時啟用，會在下載／採樣前停止。SD1.5 亦拒絕既有 Attention patches／replace；未知插件、量化權重及在線 LoRA 組合不保證相容。
- CUDA、Intel XPU、Hires、連續生成與低顯存 offload 均待實機驗收。透明解碼器執行八次增強推論，額外消耗時間與顯存。
- 圖片尺寸被其他流程改變時，沿用上游零 latent 解碼 fallback，品質可能下降。建議關閉會改變輸出尺寸的後處理。
- 英文方法值與 PNG 資訊鍵保留供 API 相容；畫面標籤、下拉選單、輸入提示與新增錯誤訊息使用繁體中文。
- 不可同時啟用其他版本 LayerDiffuse；偵測到另一份同名腳本時會拒絕載入，請先停用舊插件並重新啟動。

## 停用與更新

取消功能的「啟用」即可停止套用；也可在擴充功能頁停用本插件後重新啟動。停用不刪除權重或輸出。

本次以主專案追蹤插件原始碼，使用主專案 `git pull` 更新；不附帶插件自己的 `.git`。不修改核心 Python 程式、個人設定、既有模型及輸出。
若直接刪除受追蹤插件檔案，Git 會將它視為本地刪除，之後更新可能衝突；長期不用請在擴充功能頁停用。獨立插件庫與按鈕安裝器未在本輪建立。
